# รูปผู้สูงอายุ (elder photographs)

รูปในโฟลเดอร์นี้คือรูปที่จะ **ซ้อนทับบนภาพกล้องจริง** ตอน AR Scan เจอจุดตรวจ
(`<ElderPhoto />` → `.ar-figure` ใน `src/index.css`)

## วิธีเพิ่มรูป

1. วางไฟล์ไว้ที่ `public/elders/<elder id>.png`
   เช่น `public/elders/e-saowanee.png` — id ดูได้จาก `src/data/elders.js`
2. เพิ่มบรรทัด `photo: '/elders/<elder id>.png',` ให้ผู้สูงอายุคนนั้นใน
   `src/data/elders.js`

ใครยังไม่มีรูป จะใช้ตัวการ์ตูน `<ElderSprite />` ต่อไปตามเดิม และถ้าไฟล์หาย
หรือโหลดไม่ขึ้น ระบบก็จะถอยกลับไปใช้การ์ตูนเองอัตโนมัติ — หน้าสแกนไม่พัง

## รูปแบบไฟล์ที่แนะนำ

| หัวข้อ | ค่าที่แนะนำ |
| --- | --- |
| ไฟล์ | PNG (พื้นหลังโปร่งใสสวยที่สุด) หรือ JPG/WebP ก็ได้ |
| ขนาด | ด้านสั้น ~800–1200 px กำลังดี |
| น้ำหนักไฟล์ | ไม่เกิน ~400 KB ต่อรูป (โหลดผ่านมือถือกลางแจ้ง) |
| องค์ประกอบ | ครึ่งตัวหรือหน้าอก หัวอยู่ค่อนไปทางบน เว้นขอบรอบตัวไว้หน่อย |
| แสง | แสงนุ่ม ๆ ไม่ต้องแต่งสี — โค้ดปรับโทนให้เข้ากับภาพกล้องอยู่แล้ว |

พื้นหลังขาวก็ใช้ได้ ไม่ต้องไดคัทก็ได้ เพราะขอบรูปถูก mask ให้ฟุ้งจางหายไป
ก่อนไปทับภาพกล้องอยู่แล้ว แต่ถ้าไดคัทพื้นหลังโปร่งใสมาได้ จะกลมกลืนที่สุด

## เรื่องสิทธิ์

ใช้เฉพาะรูปที่ได้รับอนุญาตจากเจ้าของภาพ/ตัวบุคคลแล้วเท่านั้น

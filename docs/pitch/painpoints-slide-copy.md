# สไลด์ Painpoints — ข้อความสำหรับช่อง xxxx

สไลด์: **ปัญหาในปัจจุบัน: คุณค่าของผู้สูงอายุ** (Moral Hackathon 2026)
เอกสารนี้เก็บข้อความที่ใช้เติมช่องว่างสองจุดบนสไลด์ ไม่ใช่โค้ดของแอป

---

## 1. บรรทัดใต้หัวสไลด์

**เวอร์ชันที่ใช้ (อ้างตัวเลข)**

> ไทยเข้าสู่ "สังคมสูงวัยสมบูรณ์" แล้ว — ผู้สูงอายุกว่า 13 ล้านคนคือคลังภูมิปัญญาที่มีชีวิต
> แต่ถูกมองเป็น "ภาระที่ต้องดูแล" มากกว่า "ทรัพยากรที่ต้องรับฟัง"
> เรื่องเล่าและองค์ความรู้ประจำย่านจึงหายไปทีละคน โดยไม่มีใครบันทึกไว้

> ตัวเลข 13 ล้านคน = ประชากรอายุ 60 ปีขึ้นไปโดยประมาณ
> **ตรวจกับสถิติล่าสุดของ สผส./สำนักงานสถิติแห่งชาติ ก่อนนำเสนอ**
> หรือใช้เวอร์ชันสำรองด้านล่างที่ไม่อ้างตัวเลข

**เวอร์ชันสำรอง (ไม่อ้างตัวเลข)**

> ทุกวันนี้เราวัดคุณค่าของคนด้วย "กำลังการผลิต" ผู้สูงอายุที่หยุดทำงานจึงถูกนับเป็นภาระ
> ทั้งที่ในตัวพวกท่านคือประวัติศาสตร์ งานฝีมือ และเรื่องเล่าที่ไม่มีอยู่ในตำราเล่มใด
> ความรู้เหล่านี้ไม่ได้ถูกส่งต่อ — มันแค่เงียบหายไปพร้อมเจ้าของ

## 2. ข้อความในลูกศรใหญ่ (4 บรรทัดสั้น)

เชื่อมภาพซ้าย (มรดกวัฒนธรรมกำลังตายไปเงียบ ๆ) เข้ากับไดอะแกรมขวา
(นักท่องเที่ยวกับผู้สูงอายุที่ต้องการกันและกัน แต่ไม่มีจุดเชื่อม)

**เวอร์ชันที่ใช้**

```
เพราะภูมิปัญญา
ไม่ได้อยู่ในตำรา
แต่อยู่ใน "คน"
ที่ไม่มีใครฟัง
```

**เวอร์ชันสำรอง**

```
ความรู้ไม่ได้หาย        ไม่ใช่ไม่มีคนสนใจ
เพราะไม่มีค่า           ไม่ใช่ไม่มีคนเล่า
แต่เพราะ                แต่ไม่มีจุด
ไม่มีคนมาฟัง            ที่ทั้งสองฝ่ายเจอกัน
```

## เชื่อมกับสไลด์ถัดไป (Solution)

ข้อความข้างบนตั้งใจจบที่คำว่า "ขาดเครื่องมือ" เพื่อให้สไลด์ Solution รับต่อได้ทันที —
กาลวัฒน์คือเครื่องมือนั้น: นักท่องเที่ยวเดินตามเส้นทาง สแกนเจอผู้สูงอายุในโหมด AR
ฟังเรื่องเล่าที่ผูกกับสถานที่จริง ส่วนผู้สูงอายุได้ **แต้มภูมิปัญญา**
ที่แลกเป็นบริการสวัสดิการในชีวิตจริงได้ (พาไปโรงพยาบาล · ตัดผมที่บ้าน · ตรวจสุขภาพถึงบ้าน)
